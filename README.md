# forum-framework
Working on a forum/social media framework with a posts, comments, message inbox, moderation and friends system as well as DB management. Working on file management. Will I finish this? Who knows! Not for redistribution.

All passwords hashed. All inputs (hopefully) sanitized. Basic markdown allowed for posts.

## Notes for self:
- Moderation system currently just flags, has to be assigned via direct database commands. Contains a "moderator?" and "banned?" flag.
- Very in-progress profile system
- Friends viewer may be a bit bugged
